The dataset for this chapter is 2,400 supplier payments from a single financial year, spanning
four orders of magnitude. The conditions from the previous lesson are satisfied, so a Benford test
is legitimate.

<h2 id="chi-square">The chi-square test</h2>

The chi-square goodness-of-fit test compares observed digit counts against Benford's expected
counts:

$$
\chi^2 = \sum_{d=1}^{9} \frac{(O_d - E_d)^2}{E_d}, \qquad E_d = n \log_{10}\!\left(1 + \frac{1}{d}\right)
$$

With 9 categories and no parameters estimated from the data, there are 8 degrees of freedom. The
critical value at the 5% level is 15.51.

- $H_0$: the leading digits follow Benford's law.
- $H_1$: they do not.

A large $\chi^2$ and a small p-value reject conformity.

<h2 id="mad">Mean absolute deviation</h2>

MAD is the average absolute gap between observed and expected **proportions**:

$$
MAD = \frac{1}{9}\sum_{d=1}^{9} \left| p_d^{\text{obs}} - p_d^{\text{Benford}} \right|
$$

Crucially, **MAD does not depend on sample size**. Nigrini's conventional thresholds for
first-digit tests:

| MAD | Interpretation |
| --- | --- |
| 0.000 – 0.006 | Close conformity |
| 0.006 – 0.012 | Acceptable conformity |
| 0.012 – 0.015 | Marginal conformity |
| above 0.015 | Nonconformity |

<PythonCell label="MAD, and drilling into the anomaly">
{`observed_proportion = observed_counts / len(amounts)
mad = np.abs(observed_proportion - benford).mean()

def classify(value):
    if value < 0.006:
        return "close conformity"
    if value < 0.012:
        return "acceptable conformity"
    if value < 0.015:
        return "marginal conformity"
    return "NONCONFORMITY"

print()
print("Now the useful part: which vendor is responsible?")

    lambda values: np.abs(

print(f"  amounts from {flagged.min():,.2f} to {flagged.max():,.2f}")

The picture is now specific: one vendor's payments cluster just under 10,000, which is exactly the
signature of amounts being kept below an approval threshold. That is a finding an auditor can act
on — and it was invisible in the aggregate test, which only said "something is wrong somewhere."

<h2 id="reading-the-result">Reading the result</h2>

The two measures disagree systematically, and the reason matters.

**Chi-square scales with $n$.** Double the sample and the statistic roughly doubles for the same
proportional deviation. On tens of thousands of records, any tiny departure becomes "significant" —
and real data always departs a little.

**MAD does not scale with $n$.** It measures effect size, which is what an auditor actually wants:
not "is this deviation detectable?" but "is it big enough to care about?"

{`rng = np.random.default_rng(88)

<Callout title="A failed test is a lead, not a finding" variant="pitfall">
  <p>
    Benford analysis identifies data worth examining. It never establishes fraud. Round-number
    preference, approval thresholds, seasonal billing cycles, a single large contract and a dozen
    other innocent mechanisms all produce non-conformity. The correct output of this lesson is a
    prioritised list of accounts to look at by hand.
  </p>
</Callout>
