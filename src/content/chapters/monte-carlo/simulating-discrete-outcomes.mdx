The previous lesson simulated one variable in isolation. Real problems have several interacting
ones, and state that carries forward — which is exactly where closed-form answers stop being
available and simulation starts earning its keep.

<h2 id="building-the-distribution">Building the distribution</h2>

The scenario: a workshop stocks a spare part. Each day brings uncertain demand and, separately,
uncertain resupply. Unmet demand is lost, and holding stock costs money. What reorder point
minimises total cost?

Three uncertain inputs, one carried state, and a policy to choose. Nothing here has a tidy
formula.

<PythonCell label="The model's inputs">
{`import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(31)

demand_values = np.array([0, 1, 2, 3, 4, 5])

    "holding_per_unit_per_day": 0.35,
    "stockout_per_unit": 9.00,
    "order_placement": 22.00,

<h2 id="running-trials">Running the trials</h2>

The simulation walks day by day. Each day: demand arrives, stock is consumed, a stockout is
recorded if demand exceeds stock, any outstanding delivery arrives on schedule, and a new order is
placed if stock has fallen to the reorder point.

Note that this loop **cannot** be vectorised in the obvious way, because each day depends on the
one before. That path dependence is precisely why the problem needs simulation.

<PythonCell label="One inventory policy, simulated many times">
{`def simulate_policy(reorder_point, order_quantity, days=365, runs=400, seed=0):
    """Return per-run total cost and service level for one (s, Q) policy."""
    generator = np.random.default_rng(seed)
    total_costs = np.empty(runs)
    service_levels = np.empty(runs)

    for run in range(runs):
        stock = order_quantity
        pending_arrival = -1          # day index the outstanding order lands
        holding = stockouts = orders = 0.0
        demanded = served = 0.0

        for day in range(days):
            if day == pending_arrival:
                stock += order_quantity
                pending_arrival = -1

            demand = generator.choice(demand_values, p=demand_probability)
            demanded += demand
            sold = min(demand, stock)
            served += sold
            stock -= sold
            stockouts += demand - sold

            holding += stock
            if stock <= reorder_point and pending_arrival < 0:
                orders += 1
                lead = generator.choice(lead_values, p=lead_probability)
                pending_arrival = day + lead

        total_costs[run] = (
            holding * costs["holding_per_unit_per_day"]
            + stockouts * costs["stockout_per_unit"]
            + orders * costs["order_placement"]
        )
        service_levels[run] = served / demanded

    return total_costs, service_levels

annual_cost, service = simulate_policy(reorder_point=6, order_quantity=25, seed=7)

print(f"Policy: reorder at 6 units, order 25")
print(f"  mean annual cost   {annual_cost.mean():>10,.2f}")
print(f"  median             {np.median(annual_cost):>10,.2f}")
print(f"  5th percentile     {np.percentile(annual_cost, 5):>10,.2f}")
print(f"  95th percentile    {np.percentile(annual_cost, 95):>10,.2f}")
print(f"  mean service level {service.mean():>10.4f}")`}
</PythonCell>

<h2 id="analysing">Analysing the results</h2>

With a simulator in hand, comparing policies is a loop. The valuable output is not which policy
has the lowest mean — it is the whole distribution, because a policy with a slightly better
average and a much worse tail is usually the wrong choice.

<PythonCell label="Comparing policies on their whole distribution">
{`policies = [(3, 20), (6, 25), (6, 40), (10, 25), (10, 40), (14, 30)]

rows = []
distributions = {}
for reorder_point, quantity in policies:
    total, level = simulate_policy(reorder_point, quantity, seed=7)
    distributions[(reorder_point, quantity)] = total
    rows.append({
        "reorder at": reorder_point,
        "order qty": quantity,
        "mean cost": total.mean(),
        "p95 cost": np.percentile(total, 95),
        "worst": total.max(),
        "service": level.mean(),
    })

summary = pd.DataFrame(rows).sort_values("mean cost")
print(summary.round(3).to_string(index=False))

best = summary.iloc[0]
print()
print(f"Lowest mean cost: reorder at {best['reorder at']:.0f}, "
      f"order {best['order qty']:.0f}")

fig, (left, right) = plt.subplots(1, 2, figsize=(9.5, 3.6))
for key in [(3, 20), (6, 25), (10, 40)]:
    left.hist(distributions[key], bins=30, alpha=0.55, label=f"s={key[0]}, Q={key[1]}")
left.set_xlabel("annual cost")
left.set_ylabel("runs")
left.set_title("Cost distributions overlap substantially")
left.legend(fontsize=8)

means = [row["mean cost"] for row in rows]
p95s = [row["p95 cost"] for row in rows]
labels = [f"{p[0]},{p[1]}" for p in policies]
positions = np.arange(len(policies))
right.barh(positions - 0.2, means, height=0.4, label="mean")
right.barh(positions + 0.2, p95s, height=0.4, label="95th percentile")
right.set_yticks(positions)
right.set_yticklabels(labels, fontsize=8)
right.set_xlabel("annual cost")
right.set_title("Mean vs. tail")
right.legend(fontsize=8)

<PythonCell label="Is the difference real, or Monte Carlo noise?">
{`a = distributions[(6, 25)]
b = distributions[(10, 40)]

difference = a.mean() - b.mean()
se = np.sqrt(a.var(ddof=1) / len(a) + b.var(ddof=1) / len(b))

print(f"policy (6, 25) mean cost  {a.mean():>10,.2f}")
print(f"policy (10, 40) mean cost {b.mean():>10,.2f}")
print(f"difference                {difference:>10,.2f}")
print(f"standard error            {se:>10,.2f}")
print(f"95% interval on the difference: "
      f"[{difference - 1.96 * se:,.2f}, {difference + 1.96 * se:,.2f}]")

verdict = ("a real difference" if abs(difference) > 1.96 * se
           else "indistinguishable at this number of runs")
print(f"-> {verdict}")

print()
print("How often does each policy actually come out cheaper, run for run?")
print(f"  (6, 25) cheaper in {(a < b).mean():.1%} of paired runs")

print()
print("Increasing the number of runs shrinks the interval:")
for runs in [100, 400, 1600]:
    total_a, _ = simulate_policy(6, 25, runs=runs, seed=7)
    total_b, _ = simulate_policy(10, 40, runs=runs, seed=7)
    diff = total_a.mean() - total_b.mean()
    error = np.sqrt(total_a.var(ddof=1) / runs + total_b.var(ddof=1) / runs)
    print(f"  {runs:>5} runs: difference {diff:>9,.2f} +/- {1.96 * error:>8,.2f}")`}
</PythonCell>

<Callout title="Always quantify the simulation's own uncertainty" variant="pitfall">
  Two policies whose mean costs differ by less than the Monte Carlo standard error are not
  distinguishable, and picking the lower one is picking noise. Reporting a simulated mean without
  its standard error is the same error as reporting a regression coefficient without its — and it
  is much more common, because a simulation feels like a measurement rather than an estimate.
</Callout>
